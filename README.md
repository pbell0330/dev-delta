
# 🎮 GameVault

## Project Information
- Author: Parker Bell
- Project: dev|delta
- Version: 1.0
- Description: Game backlog tracker with authentication, user roles, and CRUD functionality.

## Features
- Admin and regular user login accounts
- Role-based access control
- JSON game data
- Add, view, edit, and delete games
- Search and filter games
- Session storage for application data
- Admin dashboard with application state
- Sign out functionality
